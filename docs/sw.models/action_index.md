## 5. Anomalies

### 5.1 Resource declared in XML, never acquired in Lua (8)

No directai diagnostic; the resource is still created. Often a parent whose child skill acquires it.

- `common.agent.behaviors.skills.BuildInstantaneously`: `buildCapacity`
- `common.agent.behaviors.skills.actions.ExtractDead`: `extractioncapacity`
- `common.agent.behaviors.skills.actions.ExtractWounded`: `extractioncapacity`
- `common.agent.behaviors.skills.primitives.Deconstruct`: `buildCapacity`
- `military.agent.skills.DestroyWithGroundToAirMissiles`: `directFireCapacity`
- `military.agent.skills.MonitorWithRadars`: `radarCapacity`
- `military.agent.skills.primitives.Respond`: `directFireCapacity`
- `military.agent.skills.primitives.SupportWithFires`: `supportCapacity`

### 5.2 `acquire` on a node without `select` (2)

Only selectable nodes consume resources, so this `acquire` does nothing.

- `navy.agent.skills.AirDisembarkFromLandingShipDock`
- `navy.agent.skills.ParallelLoad`

### 5.3 startStopAction without `started` used as a condition (6)

Every definition of the method lacks `started`, so the call returns nothing and the condition is never true.

- `controlIt` in `military.agent.skills.actions.Control`
- `decreaseResourceProduction` in `common.agent.behaviors.skills.actions.RestrainProduction`
- `equipWithNBCProtection` in `common.agent.behaviors.skills.actions.EquipWithNBCProtection`
- `increaseResourceProduction` in `common.agent.behaviors.skills.actions.IncreaseProduction`
- `takeAsPrisoner` in `military.agent.skills.TakePrisoner`
- `takeAsRefugee` in `military.agent.skills.TakeRefugee`

### 5.4 `spark.action` whose `start` reaches a kernel starter but has no `stop` (0)

The kernel does not stop actions on mission change; without `stop` the action keeps running.

None.
