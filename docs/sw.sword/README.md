# sw.sword knowledge base (for the sw-sword-navigator agent)

The navigator answers from **code**. These files only save it searches:

| File | What | Maintenance |
|---|---|---|
| `THEMES.md` | French↔English vocabulary, theme → files map, non-obvious gotchas with `path::anchor` | hand-written, paths only, no line numbers; checked by `tools/check_themes.py` |
| `dec_function_index.md` | every name registered into the Lua brain → file:line, bound C++, usage counts | generated by `tools/build_dec_index.py` |
| `archive/` | the original prose study (hub + 5 deep dives, 2026-11-04, sw.sword `ffbf1a501a`) | frozen, for human reading; drifts, not used by the agent; its relative links are broken by the move |

After pulling sw.sword (or switching branches), from the forge root:

```sh
python -I tools/build_dec_index.py C:/MASARepo/sw.sword C:/MASARepo/sw.models C:/MASARepo/sw.soult docs/sw.sword/dec_function_index.md
python -I tools/check_themes.py sw.sword   # exit 1 + list of stale paths/anchors in THEMES.md and the agent prompt (no argument: every kit)
```

When the navigator returns **Map updates**, apply them to `THEMES.md` and re-run the checker.
